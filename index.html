La anatomía de una instrucción

El código

nombre = "Lucía"
edad = 19
print(nombre, edad)

¿Qué significa?

  • nombre: variable que almacena texto.
  • =: asignación de un valor.
  • edad: variable numérica.
  • print(): muestra información.

Las comillas indican texto. Python distingue mayúsculas y minúsculas: Edad y edad no son la misma variable.

17 / 27  —  ENTRADA

¿Cómo pedir información?

Sin convertir

a = input("Primer número: ")
b = input("Segundo número: ")
print(a + b)

Si escribes 2 y 3, muestra 23.

Convirtiendo a número

a = float(input("Primer número: "))
b = float(input("Segundo número: "))
print(a + b)

Si escribes 2 y 3, muestra 5.0.

La diferencia es el tipo de dato, no el símbolo +.

19 / 27  —  LÓGICA

¿Cómo toma decisiones Python?

Condición

operacion = "+"

if operacion == "+":
    print("Sumar")
else:
    print("Otra operación")

Interpretación

  • if: si la condición es verdadera.
  • ==: compara valores.
  • else: alternativa.
  • Los espacios al inicio (indentación) indican qué instrucciones pertenecen al bloque.
En la calculadora elegiremos una operación y ejecutaremos solo el cálculo correspondiente.

22 / 27  —  PROYECTO

Calculadora completa · Código listo para ejecutar

Este es el programa completo. Puedes copiarlo en calculadora.py o en una celda de Colab.

print("=== CALCULADORA PYTHON ===")
print("1. Sumar")
print("2. Restar")
print("3. Multiplicar")
print("4. Dividir")

opcion = input("Elige una opción (1-4): ")

if opcion not in ("1", "2", "3", "4"):
    print("Opción no válida")
else:
    try:
        a = float(input("Primer número: "))
        b = float(input("Segundo número: "))

        if opcion == "1":
            resultado = a + b
        elif opcion == "2":
            resultado = a - b
        elif opcion == "3":
            resultado = a * b
        elif b == 0:
            print("No se puede dividir entre cero")
            resultado = None
        else:
            resultado = a / b

        if resultado is not None:
            print("Resultado:", resultado)
    except ValueError:
        print("Debes escribir números válidos")
